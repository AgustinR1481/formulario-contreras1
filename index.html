Formulario Contreras

Publicación 50: archivos del complemento disponibles.

El formulario se utiliza desde Excel. Esta página confirma que la publicación de GitHub Pages está activa; no contiene una base de empleados.

  1. Abra su Excel de SharePoint.
  2. En Complementos → Opciones avanzadas → Cargar mi complemento, seleccione el XML de instalación.
  3. En Inicio, use el botón Formulario Contreras.

Esta versión incluye Cargar/Actualizar con usuario Microsoft. Buscar, Eliminar y PDF se incorporarán después.
