# Formulario Contreras — complemento de Excel

Entrega 50. Panel de Cargar/Actualizar con identificación del usuario Microsoft, basado en la prueba 49 confirmada en Excel Web.

## Publicación

GitHub Pages: rama `main`, carpeta `/(root)`.

URL prevista: https://agustinr1481.github.io/formulario-contreras/

En Excel Web, cargar `manifest.xml` desde Complementos → Opciones avanzadas → Cargar mi complemento. El botón aparece en Inicio, grupo Contreras.

El código usa Office.js en el cliente para trabajar con el libro abierto. Este repositorio no incluye registros de empleados, credenciales ni una base de datos. No cargar archivos Excel, exportaciones ni capturas de datos en este repositorio.

Esta versión incluye Cargar/Actualizar y limpieza posterior; los demás botones actuales se conservan por separado. La instalación manual es una prueba por navegador, no un despliegue centralizado para toda la empresa.
